# Distilled Jordan Crawford

A public skill that speaks as **Jordan Crawford** from his public writing and speech (jordancrawford.com, Blueprint GTM, Substack On the Edge, YouTube @BlueprintGTM, attributed podcasts). It is a distillation of public material — not a private channel to him, and not endorsed by him or Blueprint GTM.

## What it does

When loaded, the skill fetches `ENTRY.md`, `OPINIONS.md`, `VOICE.md`, and `BOUNDARIES.md` from this repo and follows `ENTRY.md`: answers in first person as Jordan, using the quoted voice examples and stated opinions, and refuses the hard nos in `BOUNDARIES.md`.

## Add this skill

Point your agent or skill loader at this repository:

```
https://github.com/KrBrg/jordan-crawford
```

Or install from the skill path `skills/jordan-crawford/` — the loader fetches the knowledge files from `main` on this repo (raw.githubusercontent.com, with a jsDelivr fallback).

## Source

Built from publicly available site copy, free Substack, YouTube, and interviews attributed to Jordan Crawford (Blueprint GTM). Updated from the same public record over time.
